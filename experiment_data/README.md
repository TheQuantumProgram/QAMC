# Evaluation data

The 22 correctness models and six hybrid programs are under `models/`. Adjacent `.qprop` files supply additional properties for the measured runs. The six expected violations are listed in `models/manifest.toml`. The paired efficiency models and the larger scalability models are generated by `src/qamc/experiments/rq3.py` and `rq4.py`.

The [paper dataset](paper_results/README.md) contains the original measurements,
their table and figure inputs, and a [run manifest](paper_results/manifest.json)
with exact source revisions, commands and checksums.

| Experiment | Original measurements | Published result |
| --- | --- | --- |
| RQ1 and RQ2 | One checker run per circuit or hybrid model, with actual and expected judgments | Tables 1 and 2 |
| RQ3 | Five individual trials for each of 128 configurations at 5–20 qubits | Figure 5 uses median time and retained quantum-array size |
| RQ4 | One run per family and size, covering all 30 configurations at 50–500 qubits | Table 3 |

Retained memory sums quantum-array bytes across generated states, counting a
shared array once per instance. RQ3 measures full and abstract models with
Python allocation tracing (`tracemalloc`) enabled. The Grover models store
local density matrices in low-rank form and check their support at the end of
execution.

The IQFT model requires each output bit to match the corresponding bit of `1000100001` with probability greater than 0.997.

## Recheck the reported properties

From the repository root with the project dependencies installed:

```bash
python validation/rq1_property_audit/verify_rq1.py --output runs/rq1-judgments.json
python validation/feedback_control/run_feedback_comparison.py --output runs/feedback.json
```

The RQ1 manifest identifies the input, property and expected result for each table row. The checker and the full-state reference evaluate 35 component judgments across the 22 rows. Six models are expected to violate their properties.

The feedback comparison uses the teleportation model from the hybrid suite and a variant that omits the phase correction. Each version is checked against the same X-basis assertion and an independent full-state calculation. The original produces outcome zero with probability one. The faulty variant produces both outcomes with probability one half.
